# ClerkAI / Clark AI

Repository operativo per il SaaS di segreteria AI.

## Stato

Il progetto sorgente attuale è ancora ospitato in Lovable (`assistant-call-sync`). Questo repository è stato inizializzato per spostare sviluppo, controlli, correzioni e deploy su GitHub e Vercel senza utilizzare crediti Lovable.

Non inserire mai chiavi API, token OAuth, credenziali Stripe, Twilio, Meta, Google, ElevenLabs o Supabase nel repository.
